## OpenAI-compatible metadata opt-out

Time: 2026-06-11T02:45:00+08:00

Scope:

- Investigated the live remote model-smoke failure after serving from the `codex-1883251-20260611T0215` release overlay.
- Root cause: the OpenAI-compatible reverse-tunnel gateway rejected the Responses `metadata` request field, but the app only received a generic upstream gateway error. The existing automatic retry catches direct `Unsupported parameter: metadata` errors, but cannot recover when the provider hides the original parameter name.
- Added `OPENAI_DISABLE_METADATA=true` / `OPENAI_RESPONSES_DISABLE_METADATA=true` support so operators can explicitly omit Responses `metadata` for compatible gateways that mask upstream validation details.
- `/agent/model/status` now exposes `metadata_enabled` as a safe boolean and still never returns the API key.
- Updated remote deployment and OpenAI SDK boundary docs to make this an explicit operational setting, not an ad hoc remote-only workaround.
