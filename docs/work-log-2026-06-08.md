Changes:

- Replaced `tools/restart_remote_image_agent_api.sh` with a guarded restart flow:
  - loads remote `.env` from the API directory;
  - refuses restart while tasks are `queued` or `running`;

  - starts uvicorn with configurable `IMAGE_AGENT_API_HOST`, `IMAGE_AGENT_API_PORT`, and `IMAGE_AGENT_API_BASE`;
  - waits up to `IMAGE_AGENT_START_TIMEOUT_SECONDS` for post-restart `/health` to return `app=image_agent`;
  - prints `api.out` tail on startup health failure.
- Added static restart safety contract tests in `apps/api/tests/test_remote_restart_script.py`.
